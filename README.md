# NOIR ATELIER — Luxury Clothing Store (Shopify OS 2.0 Theme + Live Demo)

**Live demo:** https://ammad-codes.github.io/noir-atelier/

Editorial, high-fashion clothing store with premium motion design: page loader with curtain reveal, custom cursor, magnetic & "expensive" buttons (gold shine sweep + mouse-direction fill), liquid image hover swap, 3D tilt category cards with glare, mask text reveals, image clip-path wipes, horizontal scroll lookbook, countdown, 3D testimonial carousel, flying image add-to-cart and a slide-in cart drawer. Fully responsive, respects `prefers-reduced-motion`.

- `/` — static live demo (HTML, CSS, vanilla JS) for GitHub Pages
- `/shopify-theme` — complete Shopify Online Store 2.0 theme (Liquid, JSON templates, section groups, AJAX Cart API) and `noir-atelier-theme.zip`

### Install the theme
Shopify Admin → Online Store → Themes → Add theme → Upload zip file → choose `shopify-theme/noir-atelier-theme.zip` → Customize → Publish.
